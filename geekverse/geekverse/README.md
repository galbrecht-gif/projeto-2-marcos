# GeekVerse

## Descrição
GeekVerse é uma landing page pública sobre **Cultura Geek**, reunindo games, filmes,
séries, animes, mangás, tecnologia e curiosidades em um só lugar. O projeto é
totalmente estático (sem backend e sem banco de dados) e pronto para publicação
no GitHub Pages.

## Tecnologias utilizadas
- HTML5
- CSS3 (Flexbox, Grid e Media Queries)
- JavaScript (ES6)

## Funcionalidades
- Header fixo com logo e menu de navegação por âncoras
- Banner principal com chamada e botão de exploração
- 4 categorias: Games, Filmes e Séries, Animes e Mangás, Tecnologia
- 6 cards de destaque com área visual, título, descrição e link
- Seção "Você Sabia?" com curiosidades geek
- **Modo claro/escuro** (salvo no navegador)
- **Curiosidade aleatória** exibida a cada clique
- Menu responsivo para celular
- Layout responsivo para computador, tablet e celular
